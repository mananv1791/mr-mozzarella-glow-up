# Mr. Mozzarella Glow Up

A modern restaurant website rebuild for Mr. Mozzarella, designed to improve brand presentation, menu discovery, location browsing, franchise interest, and customer conversion.

## Highlights

- Multi-page TanStack Start website with menu, locations, franchise, about, signup, and contact routes.
- Mobile-friendly restaurant experience with reusable site sections and accessible UI primitives.
- Conversion-focused structure for online ordering, customer signup, location discovery, and franchise inquiries.
- Polished visual system using Tailwind CSS, Radix UI components, lucide icons, and responsive layout patterns.

## Stack

TanStack Start, React, TypeScript, Vite, Tailwind CSS, Radix UI, shadcn-style components, lucide-react, Vercel.

## Scripts

```bash
npm install
npm run dev
npm run build
```
